# RG Digital

RG Digital is the company Dimitri de Jong set up in the Netherlands to build his own projects and software for small businesses. Its open-source projects live here.

## Projects

- **[Haunt](https://github.com/rg-digital-dev/haunt)**: a desktop git client that also maps your code: changes by function, call paths, imports, and what a change could break.
- **[polysyntax](https://github.com/rg-digital-dev/polysyntax)**: free, local, test-driven exercises for learning another programming language in your own editor.

More at [rg-digital.dev](https://rg-digital.dev).
